**최종 업데이트**: 2026-02-19

## 기능 목적

활성 종목에 대해 SMA, RSI, MACD 등 기술적 지표를 계산하고 매수 추천 신호를 생성하는 기능.
매일 23:05(KST)에 `ParallelAnalysisJob`이 감정 분석과 함께 병렬 실행됩니다.

---

## 범위

### 포함
- 기술 지표 계산(SMA/RSI/MACD)
- 매수 추천 신호 생성
- `ParallelAnalysisJob` 스케줄 실행 연계
- MongoDB 추천 데이터 저장

### 제외
- 계산식 세부 파라미터 정의
- 데이터 스키마 상세(JSON 샘플)
- 처리 파이프라인 상세 시퀀스
- 구현 파일 단위 설명
