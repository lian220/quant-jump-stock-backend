# 기술적 분석

**최종 업데이트**: 2026-02-13

---

## 개요

활성 종목에 대해 SMA, RSI, MACD 등 기술적 지표를 계산하고 매수 추천 신호를 생성하는 기능.
매일 23:05(KST)에 `ParallelAnalysisJob`이 감정 분석과 함께 병렬로 실행한다.

---

## 스케줄러

| 항목 | 값 |
|------|-----|
| **Quartz Job** | `ParallelAnalysisJob` |
| **Job 이름** | `parallelAnalysisJob` |
| **Cron 표현식** | `0 5 23 * * ?` (Asia/Seoul) |
| **실행 시간** | 매일 23:05 KST |

**`ParallelAnalysisJob`의 동작:**
- `AnalysisUseCase.triggerTechnicalAnalysis()` + `AnalysisUseCase.triggerSentimentAnalysis()`를 `CompletableFuture.allOf()`로 병렬 실행
- 순차 실행 대비 약 40% 시간 단축
- 각 분석은 독립적이므로 하나가 실패해도 다른 하나에 영향 없음

**실행 시간 근거:**
- ISM PMI 발표(23:00 KST) 직후
- 22:00의 Vertex AI 예측 결과를 기술적 지표로 검증
- 00:30 자동 매수 전 최종 검증 단계

---

## 파이프라인

```
23:05  ParallelAnalysisJob.execute()
       │
       ├─ analysisUseCase.triggerTechnicalAnalysis()
       │   → Kafka 발행: analysis.technical.request
       │   → Data Engine: TechnicalAnalysisHandler.handle()
       │   → TechnicalAnalysisService.analyze_stocks()
       │   → MongoDB: stock_recommendations 저장
       │
       └─ analysisUseCase.triggerSentimentAnalysis() (병렬)
           → (뉴스감정분석.md 참조)
```

## 구현 상세

### Core (Kotlin)

| 파일 | 경로 |
|------|------|
| Job | `scheduler/ParallelAnalysisJob.kt` |
| QuartzConfig 등록 | `scheduler/QuartzConfig.kt` |
| UseCase | `domain/analysis/port/input/AnalysisUseCase` |

### Data Engine (Python)

| 파일 | 경로 |
|------|------|
| Kafka 핸들러 | `adapter/input/kafka/handlers.py` → `TechnicalAnalysisHandler` |
| 서비스 | `application/services/technical_analysis.py` → `TechnicalAnalysisService` |
| Kafka 토픽 | `analysis.technical.request` |

### 분석 로직

**데이터 준비:**
1. PostgreSQL `stocks` 테이블에서 활성 종목 조회 (is_active=true)
2. MongoDB `daily_stock_data`에서 최근 180일 데이터 로드

**지표 계산:**

| 지표 | 파라미터 | 설명 |
|------|----------|------|
| SMA(20) | 단기 20일 | 단순이동평균 |
| SMA(50) | 장기 50일 | 단순이동평균 |
| RSI(14) | 기간 14일 | 상대강도지수 (0~100) |
| MACD | fast=12, slow=26, signal=9 | 이동평균수렴확산지수 |

**매수 신호 생성:**
```
is_recommended = golden_cross AND (rsi < 50) AND macd_buy_signal

where:
  golden_cross   = SMA(20) > SMA(50)
  macd_buy_signal = MACD > Signal Line
```
