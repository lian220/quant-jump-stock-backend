# 추천 시스템 (Composite Score)

**최종 업데이트**: 2026-02-13

---

## 개요

기술적 분석 완료 후 **Composite Score** 기반으로 매수 후보를 필터링·점수 계산하여 Slack으로 알림하는 시스템.
banbu-stocktrading의 매수 기준을 객체화(`BuyCriteria`)하여 향후 AI예측·감정분석 통합 시 자연스럽게 확장된다.

---

## 점수 공식

### Composite Score

```
composite_score = 0.3 × ai_score + 0.4 × tech_score + 0.3 × sentiment_score
```

| 구성 요소 | 가중치 | 현재 상태 |
|-----------|--------|-----------|
| AI 예측 (rise_probability) | 0.3 | 미통합 (0) |
| 기술적 점수 (tech_score) | 0.4 | ✅ 적용 |
| 감정 점수 (sentiment_score) | 0.3 | 미통합 (0) |

### 기술적 점수 (tech_score, max 3.5)

```
tech_score = 1.5 × golden_cross + 1.0 × (RSI < 50) + 1.0 × MACD매수
```

| 신호 | 점수 | 조건 |
|------|------|------|
| 골든크로스 | 1.5 | SMA(20) > SMA(50) |
| RSI 과매도 | 1.0 | RSI(14) < 50 |
| MACD 매수 | 1.0 | MACD > Signal Line |

### 현재 상태에서의 점수 범위

AI=0, 감정=0이므로:
- `composite_score = 0.4 × tech_score`
- tech_score max = 3.5 → **composite max = 1.4**
- min_composite_score = 2.0 → **현재는 매수 후보 0개가 정상**

AI예측·감정분석 통합 시 자연스럽게 점수가 올라간다.

---

## 필터 조건

```
감정 ≥ 0.15 → 기술 신호 2/3개 이상 충족
감정 < 0.15 또는 없음 → 기술 신호 3/3개 충족
composite_score ≥ 2.0
```

최종 결과는 composite_score 내림차순, 상위 5개(max_stocks_to_recommend).

## 데이터 흐름

```
23:05  ParallelAnalysisJob.execute()
       │
       └─ triggerTechnicalAnalysis()
           → Kafka: analysis.technical.request
           → Data Engine: TechnicalAnalysisHandler
           → TechnicalAnalysisService.analyze_stocks()
              → all_results: 전체 종목 기술지표
           → BuyCriteria.filter_candidates(all_results)
              → 필터 + composite score 계산 + 정렬
              → buy_candidates (상위 5개)
           → SlackNotifier.notify_buy_candidates()
              → SLACK_WEBHOOK_URL_ANALYSIS 로 Block Kit 전송
```

## 구현 파일

### Data Engine (Python)

| 파일 | 역할 |
|------|------|
| `services/buy_criteria.py` | `BuyCriteria` — 매수 기준 설정 + 점수 계산 + 필터링 |
| `services/technical_analysis.py` | `TechnicalAnalysisService` — 기술 지표 계산, `all_results` 반환 |
| `services/recommendation_service.py` | `RecommendationService` — 분석 오케스트레이션 |
| `services/slack_notifier.py` | `SlackNotifier.notify_buy_candidates()` — Slack 알림 |

### BuyCriteria 설정값

```python
@dataclass
class BuyCriteria:
    # Composite score 가중치
    weight_ai: float = 0.3
    weight_technical: float = 0.4
    weight_sentiment: float = 0.3

    # 기술적 점수 개별 가중치
    golden_cross_score: float = 1.5
    rsi_below_score: float = 1.0
    macd_buy_score: float = 1.0
    rsi_threshold: float = 50.0

    # 필터 조건
    min_composite_score: float = 2.0
    min_sentiment_for_relaxed: float = 0.15
    min_tech_signals_with_sentiment: int = 2
    min_tech_signals_without_sentiment: int = 3

    # 추천 설정
    max_stocks_to_recommend: int = 5
```
