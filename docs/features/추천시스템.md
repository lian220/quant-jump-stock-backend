**최종 업데이트**: 2026-02-14

> **관련 파일**:
> - Backend: `domain/recommendation/model/RecommendationCriteria.kt`
> - Data Engine: `services/buy_criteria.py`

---

## 📋 개요

기술적 분석 완료 후 **Composite Score** 기반으로 매수 후보를 필터링·점수 계산하여 Slack으로 알림하는 시스템.
banbu-stocktrading의 매수 기준을 객체화(`BuyCriteria`)하여 향후 AI예측·감정분석 통합 시 자연스럽게 확장된다.

---

## 📊 점수 체계 개요

종목 추천은 **3가지 점수**를 통합한 **Composite Score**를 기반으로 합니다.

```
Composite Score (0~7.5점) = AI(30%) + 기술적분석(40%) + 감정분석(30%)
                          = (0.3 × AI) + (0.4 × Tech) + (0.3 × Sentiment)
```

### 점수 공식

```
composite_score = 0.3 × ai_score + 0.4 × tech_score + 0.3 × sentiment_score
```

| 구성 요소 | 최대 점수 | 가중치 | 현재 상태 |
|-----------|-----------|--------|-----------|
| AI 예측 (rise_probability) | 2.5점 | 30% | ⚠️ 미통합 (0) |
| 기술적 점수 (tech_score) | 3.5점 | 40% | ✅ 적용 |
| 감정 점수 (sentiment_score) | 2.5점 | 30% | ⚠️ 미통합 (0) |

## 1️⃣ 기술적 분석 점수 (Tech Score)

**최대 점수**: 3.5점
**계산 위치**: Data Engine `services/buy_criteria.py:59-68`

### 점수 구성

| 지표 | 조건 | 배점 | 설명 |
|------|------|------|------|
| **골든 크로스** | SMA20 > SMA50 | **1.5점** | 단기 이평선이 장기 이평선 돌파 (강력한 매수 신호) |
| **RSI** | RSI < 50 | **1.0점** | 과매도 구간 진입 (저점 매수 기회) |
| **MACD** | MACD > Signal | **1.0점** | MACD 선이 시그널 선 상향 돌파 (추세 전환) |

### 계산 로직

```python
def calculate_tech_score(indicators):
    score = 0.0
    if indicators.get("golden_cross"):
        score += 1.5
    if indicators.get("rsi") < 50:
        score += 1.0
    if indicators.get("macd_buy_signal"):
        score += 1.0
    return score  # max 3.5
```

### 예시

```
AAPL 종목:
- Golden Cross: O (1.5점)
- RSI: 45 < 50 → O (1.0점)
- MACD 매수: X (0점)
→ Tech Score = 2.5점
```

### 현재 상태에서의 점수 범위

AI=0, 감정=0이므로:
- `composite_score = 0.4 × tech_score`
- tech_score max = 3.5 → **composite max = 1.4**
- min_composite_score = 2.0 → **현재는 매수 후보 0개가 정상**

AI예측·감정분석 통합 시 자연스럽게 점수가 올라간다.

## 2️⃣ AI 예측 점수 (AI Score)

**최대 점수**: 2.5점
**계산 위치**: Vertex AI 예측 모델 (Data Engine 통합)
**현재 상태**: ⚠️ **미구현** (Phase 6 진행 중)

### 계획된 계산 방식

1. **Vertex AI 모델**로 다음날 종가 예측
2. **상승 확률** 기반 점수화
   ```
   AI Score = min(상승확률 × 2.5, 2.5)
   ```

### 예시 (구현 후)

```
AAPL 종목:
- 예측 상승 확률: 85%
→ AI Score = 0.85 × 2.5 = 2.125점
```

## 3️⃣ 감정 분석 점수 (Sentiment Score)

**최대 점수**: 2.5점
**계산 위치**: 뉴스 감정 분석 (Data Engine 통합)
**현재 상태**: 🔄 **구현 중** (Alpha Vantage News Sentiment API)

### 계산 방식

1. **뉴스 기사** 수집 (Alpha Vantage News Sentiment API)
2. **MongoDB 저장**: `sentiment_analysis` 컬렉션
   ```json
   {
     "ticker": "AAPL",
     "date": "2026-02-14",
     "average_sentiment_score": 0.65,
     "article_count": 12,
     "articles": [
       {
         "title": "Apple announces new AI features",
         "sentiment_score": 0.85,
         "relevance_score": 0.92,
         "published_at": "2026-02-14T10:30:00Z"
       }
     ]
   }
   ```
3. **정규화** 및 점수화
   ```
   Sentiment Score = normalize(감정평균) × 2.5
   ```

### API 키 로테이션

Alpha Vantage Free Tier 제한 (25 calls/day, 5 calls/min)을 우회하기 위해 **6개 API 키 라운드 로빈** 사용:

- `ALPHA_VANTAGE_API_KEY` (레거시)
- `ALPHA_VANTAGE_API_KEY_1` ~ `_5` (`.env.common`)
- 자동 Rate Limit 감지 및 키 전환

### 예시 (구현 후)

```
AAPL 종목:
- 뉴스 10개 감정 평균: +0.6 (긍정)
→ Sentiment Score = 0.6 × 2.5 = 1.5점
```

## 4️⃣ Composite Score (통합 점수)

**최대 점수**: 7.5점
**계산 위치**: Backend `PredictionResult.calculateCompositeScore()`

### 가중치 근거

| 구분 | 가중치 | 근거 |
|------|--------|------|
| AI 예측 | **30%** | 단기 가격 예측 |
| 기술적 분석 | **40%** | 차트 패턴 및 모멘텀 (가장 중요) |
| 감정 분석 | **30%** | 시장 심리 반영 |

### 계산 공식

```kotlin
compositeScore = (aiScore × 0.3) + (techScore × 0.4) + (sentimentScore × 0.3)
```

### 현재 상태 (Phase 6 이전)

AI와 Sentiment가 미구현이므로 **Tech만 반영**:

```
Composite Score (현재) = 0.4 × Tech Score
최대 가능 점수 = 0.4 × 3.5 = 1.4점
```

**임계값 조정**:
- 기본 최소 점수: 5.25점 → **Tech-only 모드: 1.0점** (자동 조정)

## 5️⃣ 등급 판정 (Grade)

**계산 위치**: Backend `PredictionResult.determineGrade()`

| 등급 | 점수 범위 | 설명 | 색상 |
|------|-----------|------|------|
| **S** | 6.0 ~ 7.5 | 매우 강한 매수 신호 | 🟢 emerald |
| **A** | 4.5 ~ 5.9 | 강한 매수 신호 | 🔵 cyan |
| **B** | 3.0 ~ 4.4 | 보통 매수 신호 | 🟡 yellow |
| **C** | 1.5 ~ 2.9 | 약한 매수 신호 | 🟠 orange |
| **D** | 0.0 ~ 1.4 | 매수 신호 없음 | 🔴 red |

### Kotlin 코드

```kotlin
fun determineGrade(compositeScore: BigDecimal): CompositeGrade {
    return when {
        compositeScore >= BigDecimal("6.0") -> CompositeGrade.S
        compositeScore >= BigDecimal("4.5") -> CompositeGrade.A
        compositeScore >= BigDecimal("3.0") -> CompositeGrade.B
        compositeScore >= BigDecimal("1.5") -> CompositeGrade.C
        else -> CompositeGrade.D
    }
}
```

## 7️⃣ 추천 여부 결정 (isRecommended)

**계산 위치**: Backend `RecommendationDomainService.decideRecommendation()`

### 필터링 규칙

#### 규칙 1: 리스크 검증
```kotlin
if (riskLevel == EXTREME) return false  // 극한 위험 제외
```

#### 규칙 2: 최소 점수 충족
```kotlin
val minScore = when (marketContext.trend) {
    BULL -> 4.5점      // 강세장: 낮은 기준
    SIDEWAYS -> 5.0점  // 횡보장: 중간 기준
    BEAR -> 5.5점      // 약세장: 높은 기준 (보수적)
}
return compositeScore >= minScore
```

#### 규칙 3: 고위험 종목 추가 검증
```kotlin
if (riskLevel == HIGH) {
    return compositeScore >= 6.0점  // 고위험은 더 높은 점수 요구
}
```

## 필터 조건

```
감정 ≥ 0.15 → 기술 신호 2/3개 이상 충족
감정 < 0.15 또는 없음 → 기술 신호 3/3개 충족
composite_score ≥ 2.0
```

최종 결과는 composite_score 내림차순, 상위 5개(max_stocks_to_recommend).

## 🚨 개선 필요사항 (2026-02-14)

### 1. 추천 로직 변경: 부분 점수 시스템

**현재 문제**:
- `is_recommended` 필드가 기술적 분석의 **완전 충족 여부만** 반영 (이진 true/false)
- Composite Score는 부분 점수를 계산하지만, 필터링은 이진으로만 수행
- 결과적으로 추천 종목이 너무 적거나 없음 (BETA 상태에서 1.4점 최대)

**개선 방향**:
```kotlin
// ❌ Before: is_recommended 필드로만 필터링
.filter { it.isRecommended }

// ✅ After: Composite Score 기준으로 동적 필터링
.filter { it.compositeScore >= minCompositeScore }
```

**변경 파일**:
1. **Backend** (`RecommendationService.kt`):
   - `getBuySignals()` 메서드에서 `.filter { it.isRecommended }` 제거
   - Composite Score 기준으로만 필터링

2. **Data Engine** (`sync_service.py`):
   - `is_recommended` 필드를 Composite Score 기준으로 재계산
   - 새 메서드 추가: `_determine_recommended(composite_score, grade)`

**임계값 설정** (동적 조정):
```python
# BETA 상태 (AI/감정 미통합)
MIN_SCORE_BETA = 0.8  # 기술적 점수만, 최대 1.4

# 통합 후 (AI/감정 통합)
MIN_SCORE_INTEGRATED = 2.0  # C등급 이상, 최대 7.5
```

### 2. AI 분석과 종목 추천 통합

**현재 상태**:
- `/recommendations` 페이지가 이미 **AI 분석 + 기술적 분석 + 감정 분석**을 통합
- "AI 종목 분석 예시"와 중복되는 개념 없음

**통합 방안**:
- `/recommendations` = **종합 추천** (Composite Score 기반, 전체 목록)
- `/stocks/{ticker}` = **개별 종목 상세** (AI 예측, 차트, 뉴스, 펀더멘탈)
