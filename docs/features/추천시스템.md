## 📋 개요

AI 예측 · 기술적 분석 · 감정 분석 3가지를 통합한 **Composite Score** 기반 종목 추천 시스템.

매일 00:20 KST 스케줄러가 전날 날짜로 PostgreSQL `prediction_results` 테이블에 저장하고,
`/recommendations` API를 통해 프론트엔드에서 조회한다.

---

## 📊 점수 체계 개요

```
Composite Score (0~7.4점) = AI(30%) + 기술적분석(40%) + 감정분석(30%)
                          = (0.3 × AI) + (0.4 × Tech) + (0.3 × Sentiment)
최대값: 0.3×10 + 0.4×3.5 + 0.3×10 = 3.0 + 1.4 + 3.0 = 7.4점
```

### 점수 구성

| 구성 요소 | 최대 점수 | 가중치 | 계산 방식 |
|-----------|-----------|--------|-----------|
| AI 예측 (rise_probability) | **10점** | 30% | rise_probability_normalized × 10 |
| 기술적 점수 (tech_score) | **3.5점** | 40% | 골든크로스 + RSI + MACD |
| 감정 점수 (sentiment_score) | **10점** | 30% | (sentiment + 1) / 2 × 10 |

> **스케일 설계 근거**: banbu-stocktrading 원본은 rise_probability를 raw % (예: 25.0)로 사용하여
> `0.3 × 25 = 7.5`를 설계 기준으로 삼았다. quant-jump-stock은 rise_prob를 0~1로 정규화하므로
> ×10을 곱해 동일한 스케일을 유지한다. (7.4 ≈ 7.5)

## 1️⃣ 기술적 분석 점수 (Tech Score)

**최대 점수**: 3.5점
**계산 위치**: Data Engine `application/recommendation/sync_service.py`

### 점수 구성

| 지표 | 조건 | 배점 | 설명 |
|------|------|------|------|
| **골든 크로스** | SMA20 > SMA50 | **1.5점** | 단기 이평선이 장기 이평선 돌파 (강력한 매수 신호) |
| **RSI** | RSI < 50 | **1.0점** | 과매도 구간 진입 (저점 매수 기회) |
| **MACD** | MACD > Signal | **1.0점** | MACD 선이 시그널 선 상향 돌파 (추세 전환) |

### 계산 로직

```python
def _calculate_tech_score(self, tech: Dict) -> Decimal:
    score = Decimal("0")
    if tech.get("golden_cross"):
        score += Decimal("1.5")
    if tech.get("rsi") and tech["rsi"] < 50:
        score += Decimal("1.0")
    if tech.get("macd_buy_signal"):
        score += Decimal("1.0")
    return score  # max 3.5
```

### 예시

```
AAPL 종목:
- Golden Cross: O (1.5점)
- RSI: 45 < 50 → O (1.0점)
- MACD 매수: X (0점)
→ Tech Score = 2.5점
```

## 2️⃣ AI 예측 점수 (AI Score)

**최대 점수**: 10점
**계산 위치**: Data Engine `application/recommendation/sync_service.py`
**데이터 소스**: MongoDB `stock_analysis_results` (Vertex AI 예측 결과)

### 계산 방식

1. **Vertex AI 모델**로 다음날 종가 예측 → `rise_probability` (상승 예상 %)
2. **0~1 정규화** (0% = 중립 0.5, +20% = 최대 1.0, -20% = 최소 0.0)
   ```python
   rise_prob_normalized = max(0.0, min(1.0, 0.5 + rise_pct / 40.0))
   ```
3. **점수화** (×10으로 스케일)
   ```python
   def _calculate_ai_score(self, rise_probability: Optional[float]) -> Decimal:
       """AI 점수 계산: rise_probability × 10 (0~10)"""
       return Decimal(str(rise_probability)) * Decimal("10")
   ```

### 점수 예시

| 상승 예측 | 정규화값 | AI Score |
|-----------|----------|----------|
| +20% 이상 | 1.0 | 10.0점 |
| +16% | 0.9 | 9.0점 |
| 0% (중립) | 0.5 | 5.0점 |
| -20% 이하 | 0.0 | 0.0점 |

## 3️⃣ 감정 분석 점수 (Sentiment Score)

**최대 점수**: 10점
**계산 위치**: Data Engine `application/recommendation/sync_service.py`
**데이터 소스**: MongoDB `sentiment_analysis` (뉴스 감정 분석 결과)

### 계산 방식

1. **뉴스 기사** 수집 및 감정 점수 계산 (-1.0 ~ +1.0)
2. **0~10 정규화**
   ```python
   def _calculate_sentiment_score(self, sentiment: Optional[float]) -> Decimal:
       """감정 점수 정규화: (sentiment + 1) / 2 × 10 (0~10)"""
       normalized = (Decimal(str(sentiment)) + Decimal("1")) / Decimal("2") * Decimal("10")
       return normalized
   ```

### 점수 예시

| 뉴스 감정 | Sentiment Score |
|-----------|-----------------|
| +1.0 (매우 긍정) | 10.0점 |
| +0.6 (긍정) | 8.0점 |
| 0.0 (중립) | 5.0점 |
| -1.0 (매우 부정) | 0.0점 |

### MongoDB 데이터 구조

```json
{
  "ticker": "AAPL",
  "date": "2026-02-24",
  "average_sentiment_score": 0.65,
  "article_count": 12
}
```

## 4️⃣ Composite Score (통합 점수)

**최대 점수**: 7.4점
**계산 위치**: Data Engine `sync_service.py._calculate_composite_score()`

### 가중치 근거

| 구분 | 가중치 | 근거 |
|------|--------|------|
| AI 예측 | **30%** | 단기 가격 예측 |
| 기술적 분석 | **40%** | 차트 패턴 및 모멘텀 (가장 중요) |
| 감정 분석 | **30%** | 시장 심리 반영 |

### 계산 공식

```python
# 고정 분모 사용 (누락 지표는 0점 기여)
weighted_sum = weight_ai * ai_score + weight_tech * tech_score + weight_sentiment * sentiment_score
fixed_denominator = weight_ai + weight_tech + weight_sentiment  # = 1.0
composite_score = weighted_sum / fixed_denominator
```

## 5️⃣ 등급 판정 (Grade)

| 등급 | 점수 범위 | 설명 |
|------|-----------|------|
| **S** | ≥ 6.0점 | 매우 강한 매수 신호 |
| **A** | ≥ 4.5점 | 강한 매수 신호 |
| **B** | ≥ 3.0점 | 보통 매수 신호 |
| **C** | ≥ 1.5점 | 약한 매수 신호 |
| **D** | < 1.5점 | 매수 신호 없음 |

## 데이터 흐름

```
23:45  Cloud Scheduler → Vertex AI CustomJob
       │   Vertex AI 예측 결과 → MongoDB stock_analysis_results
       │
00:20  Core Quartz Scheduler (StockRecommendationJob)
       │
       └─ RecommendationSyncService.sync_latest_recommendations(전날날짜)
           │
           ├─ MongoDB stock_analysis_results → AI 예측 (rise_probability)
           ├─ MongoDB sentiment_analysis     → 감정 점수
           ├─ MongoDB stock_recommendations  → 기술 점수
           └─ Composite Score 계산 + 등급 → PostgreSQL prediction_results upsert
                                │
                                └─ Slack 리포트 전송 (TRADING 채널)

Frontend GET /recommendations?date=YYYY-MM-DD
       │
       └─ RecommendationService.getBuySignals(date, minConfidence=0.7)
           └─ compositeScore ≥ 0.7 × 7.4 = 5.18 필터링
```

### 예시 1: 고득점 종목 (S등급)

```
Composite = (0.3 × 9.0) + (0.4 × 3.5) + (0.3 × 8.0)

- Sentiment Score: 5.0점 (뉴스 감정 0.0 → 중립)

```
Composite = (0.3 × 6.0) + (0.4 × 2.5) + (0.3 × 5.0)
