# 경제 데이터 수집

**최종 업데이트**: 2026-02-13

---

## 개요

FRED(미국 연방준비은행)와 Yahoo Finance에서 경제 지표 및 시장 데이터를 수집하여 MongoDB에 저장하는 기능.
매일 22:00(KST)에 자동 실행되며, AI 예측과 기술적 분석의 입력 데이터로 활용된다.

---

## 스케줄러

| 항목 | 값 |
|------|-----|
| **Quartz Job** | `EconomicDataUpdate2JobAdapter` |
| **Job 이름** | `economicDataUpdate2Job` |
| **Cron 표현식** | `0 0 22 * * ?` (Asia/Seoul) |
| **실행 시간** | 매일 22:00 KST |

**실행 시간 근거:**
- CPI/NFP 발표(21:30 KST) 직후
- ISM PMI 발표(23:00 KST) 직전
- 주요 미국 경제 지표 발표 사이에 최신 데이터 확보

> 참고: 기존 `EconomicDataUpdateJobAdapter`(06:05, 23:00)는 현재 QuartzConfig에 등록되어 있지 않음.
> `EconomicDataUpdate2JobAdapter`가 이를 대체하며, Vertex AI 예측까지 연계 실행함.

---

## 파이프라인

```
22:00  EconomicDataUpdate2JobAdapter.execute()
       │
       ├─ [1단계] economicDataUseCase.triggerEconomicDataUpdate()
       │          → Kafka 발행: economic.data.update.request
       │          → Data Engine: EconomicDataHandler.handle()
       │          → EconomicDataService.collect_economic_data()
       │          → MongoDB: daily_stock_data 저장
       │
       └─ [2단계] Vertex AI 예측 (→ 인공지능분석.md 참조)
```

## 구현 상세

### Core (Kotlin)

| 파일 | 경로 |
|------|------|
| Job Adapter | `adapter/input/scheduler/EconomicDataUpdate2JobAdapter.kt` |
| QuartzConfig 등록 | `scheduler/QuartzConfig.kt` |
| UseCase | `domain/economic/port/input/EconomicDataUseCase` |

`EconomicDataUpdate2JobAdapter`는 2단계로 실행:
1. `economicDataUseCase.triggerEconomicDataUpdate()` — Kafka로 경제 데이터 수집 요청
2. `runVertexAIPrediction()` — Vertex AI 예측 실행 (GCP 활성화 시)

### Data Engine (Python)

| 파일 | 경로 |
|------|------|
| Kafka 핸들러 | `adapter/input/kafka/handlers.py` → `EconomicDataHandler` |
| 서비스 | `application/services/economic_data/service.py` → `EconomicDataService` |
| Kafka 토픽 | `economic.data.update.request` |

**`EconomicDataService.collect_economic_data()` 처리 흐름:**

1. PostgreSQL에서 활성 지표 목록 로드
   - `fred_indicators` 테이블 (is_active=true)
   - `yfinance_indicators` 테이블 (is_active=true)
2. FRED API로 경제 지표 수집 (최근 365일)
3. Yahoo Finance로 시장 지표 수집
4. PostgreSQL `stocks` 테이블에서 활성 종목 조회 → yfinance로 개별 OHLCV 수집
5. 날짜별로 통합하여 MongoDB `daily_stock_data`에 upsert

## 외부 API

### FRED API
- **용도**: GDP, CPI, 실업률, 10년물 국채 금리, USD/KRW 환율 등
- **설정**: `FRED_API_KEY` 환경변수
- **호출 주기**: 1일 1회 (365일 lookback)
- **제한사항**: 분당 120회 요청 제한

### Yahoo Finance (yfinance 라이브러리)
- **용도**: S&P500, Dow Jones, NASDAQ, KOSPI, Gold 등 ETF 가격 + 개별 종목 OHLCV
- **설정**: API 키 불필요 (공개 데이터)
- **호출 주기**: 1일 1회
