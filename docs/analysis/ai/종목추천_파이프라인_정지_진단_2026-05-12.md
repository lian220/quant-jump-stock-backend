## 권장 액션 (우선순위 순)

### P0 (즉시)

1. **사용자 노출 차단**: 페이지 `/recommendations` 또는 메인의 "AI 추천" 카드를 임시 차단하거나 "데이터 갱신 중" 배너 표시. 75일 묵은 예측에 사용자 자금이 노출되는 위험 차단.
2. **운영 환경변수 확인**: 위 검증 명령 1~3 실행. 게이트 1(`VERTEX_AI_ENABLED=false`)인지, 게이트 2(필수 변수 누락)인지, 외부(Custom Job 실패)인지 단정.

### P1 (단기, 0.5~2일)

3. **데이터 freshness 알람 추가**: `stock_predictions.latestDate`가 오늘 -1일 이상 차이나면 슬랙 알람. `_vertex_ai_noop` 호출 시 INFO가 아니라 WARN + 카운터 누적, 일 1회 이상이면 알람.
4. **`sync_service` 가짜 적재 방어 (`sync_service.py:197-216`)**: fallback으로 가져온 데이터는 `ai_source_date` 컬럼 별도 저장 또는 freshness 라벨. 7일 초과면 페이지 응답에서 추천 제외 또는 stale 표시.
5. **`comprehensive_report.py:38` projection 수정**: `rise_probability` 필드를 projection에 추가. line 211-228 stock_predictions 처리 로직을 `sync_service._fetch_ai_predictions`(line 222-238)와 동일하게 통일.
6. **슬랙 메시지 가드**: AI/감정 둘 다 빠진 종목은 슬랙 추천 후보에서 제외. 동적 max 사용 시 "강력 추천 100%" 라벨 금지, `(tech-only)` 같은 출처 표시 필수.

### P2 (중기, 1주)

7. **단일 진실원 통일**: 슬랙 리포트도 MongoDB 직접 조회 대신 PostgreSQL `prediction_results`를 읽도록 변경. 페이지와 슬랙이 같은 데이터 보장.
8. **점수 스케일 일원화**: `RecommendationCriteria.kt`의 고정 7.4 vs `buy_criteria.py`의 동적 max 이중 진실원 문제 해소. 0~1 confidence 기준으로 단일화 검토.
9. **Vertex AI 영구 비활성화 결정 시**: 추천 시스템을 tech+sentiment 기반으로 재설계하고 UI 라벨에서 "AI" 표현 제거.

## 보조 발견 (별도 결함)

### B1. `_query_stock_predictions_by_date` projection 누락

`comprehensive_report.py:38`:
```python
projection = {"_id": 0, "ticker": 1, "predicted_price": 1, "actual_price": 1}
# rise_probability 누락 → 이미 저장돼 있을 값을 못 읽음
```

`sync_service.py`는 같은 필드를 그대로 사용함. AI 컬렉션이 부분 가용 상태일 때 슬랙만 더 많은 데이터를 놓치게 됨.

### B2. `predicted_price`가 None이면 무조건 skip

`comprehensive_report.py:214`:
```python
predicted = doc.get("predicted_price")
if not ticker or not predicted:
    continue
```

`sync_service._fetch_ai_predictions`는 `rise_probability`만 있어도 가져옴. 슬랙이 더 엄격해 누락 위험 큼.

### B3. sync_service fallback이 가짜 날짜로 적재

`sync_service.py:197-216` + `:683`. fallback으로 가져온 데이터를 요청한 `analysis_date`(가짜 라벨)로 PostgreSQL에 INSERT. 페이지의 모든 "오늘의 추천"이 환상이 된 원인.

### B4. 점수 스케일 이중 진실원

- Core (Kotlin): `RecommendationCriteria.MAX_SCORE = 7.4` 고정
- Data-engine (Python): 동적 max (3.5 ~ 7.4)
- 같은 종목이라도 슬랙/페이지 등급이 달라질 수 있음. compositeGrade A + priceRecommendation 매도 같은 모순 응답 흔함.

### B5. 모니터링 부재

75일간 누구도 알아채지 못한 것은:
- Vertex AI Job 실패/스킵 알람 부재
- 데이터 freshness 알람 부재
- noop 핸들러가 INFO 레벨 로그만 남겨 알람 트리거 불가
