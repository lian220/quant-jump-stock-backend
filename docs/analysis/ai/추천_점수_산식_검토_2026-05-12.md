## 검토 동기

[종목추천 파이프라인 정지 진단](./종목추천_파이프라인_정지_진단_2026-05-12.md)에서 코드 레벨 결함을 확인한 후, **각 점수 컴포넌트의 산식 자체가 검증된 적이 있는가** 라는 더 본질적 질문이 제기되었다. 코드 버그를 다 고쳐도 산식이 부실하면 정직한 거짓을 내보내는 시스템이 된다.

본 문서는 산식 자체를 *결함*으로 단정하지 않는다. **검증 기록의 부재**와 **전문가 시각에서 의심스러운 지점**을 기록하여 별도 trace(`docs/adr/0002-recommendation-fix-plan-honesty-first.md` 참조)에서 학술적 검증을 진행할 입력으로 삼는다.

## 현 산식

```
composite_score = 0.3 × ai_score + 0.4 × tech_score + 0.3 × sentiment_score
              범위: 0 ~ 7.4 (= 0.3×10 + 0.4×3.5 + 0.3×10)

ai_score        = rise_probability_normalized × 10           (0 ~ 10)
                  normalized = 0.5 + rise_pct / 40            (0%→0.5, +20%→1.0, -20%→0.0)
tech_score      = 1.5·골든크로스 + 1.0·(RSI<70) + 1.0·MACD매수 (0 ~ 3.5)
sentiment_score = (sentiment + 1) / 2 × 10                    (0 ~ 10, sentiment∈[-1,1])

Grade 임계 (RecommendationCriteria.kt):
  S ≥ 6.0, A ≥ 4.5, B ≥ 3.0, C ≥ 1.5, D < 1.5
```

## 컴포넌트별 비판

### Tech Score (0 ~ 3.5)

| 관점 | 비판 |
|---|---|
| 신호 독립성 (Simons) | 골든크로스(20/50일 SMA 교차)와 MACD(EMA 기반 모멘텀)는 **상관관계가 매우 높음**. 단순 합산은 같은 정보를 두 번 반영. |
| 신호 다양성 (Livermore/Lo) | 세 신호 모두 **모멘텀/추세 추종 계열**. 평균회귀, 거래량, 변동성, 가치 신호가 0. 끝물 강세장에서 거짓 양성 폭증 위험. |
| 임계의 헐거움 | RSI < 70은 "과매수가 아닌 모든 상태". 실제 과매도(30 이하) 또는 중립(40~50) 구간과 동일 점수. 슬랙 메시지에서 RSI 63인 NVDA가 "충족 만점"으로 통과. |
| 가중치 근거 부재 | 1.5(골든크로스) vs 1.0(RSI) vs 1.0(MACD)의 출처가 코드/문서에 없음. 백테스트 최적화 결과인지 단순 직관인지 추적 불가. |
| 위험 미조정 | 종목별 변동성/베타 무관. TSM과 WMT가 동일 임계 / 동일 점수. 위험 조정 수익률(Sharpe) 무관. |

### AI Score (0 ~ 10)

| 관점 | 비판 |
|---|---|
| 이름과 의미 불일치 | `rise_probability`라 부르지만 사실 "예측 상승률 %"(`predictions.rise_probability`). **확률과 수익률 혼동**. |
| 정규화 산식 임의성 | `0.5 + rise_pct / 40`. 분모 40의 근거 없음. +20% 가 1.0이 되는 매핑이 무엇을 의미하는지 불명. 모델 출력의 분포를 분석하여 결정된 것이 아닐 가능성. |
| 모델 자체 검증 부재 | Vertex AI Custom Job 모델(`predict_optimized.py`)의 **백테스트 정확도, Sharpe, MAE/RMSE 등 정량 검증 기록이 docs/ 어디에도 없음**. 75일 정지를 아무도 못 알아챈 사실 자체가 *결과가 측정되지 않았다*는 강한 신호. |
| 시간축 불일치 | AI prediction horizon은 14일(`_MAX_PREDICTION_LOOKBACK_DAYS = 7`의 절반 추정). 골든크로스(20일+50일 SMA) 추세와 같은 가중치로 합산. 시간축 다른 신호 평균. |
| 데이터 편향 | 분석 종목 35개의 선정 기준 미문서화. 살아남은 빅테크 위주면 **survivor bias** — 학습 데이터 자체가 시장 평균보다 우호적. |

### Sentiment Score (0 ~ 10)

| 관점 | 비판 |
|---|---|
| 단순 평균의 정보 손실 | 뉴스 N개의 sentiment 평균. 강세 +0.9 + 약세 -0.9 = 0 (중립으로 표시). 의견 양극화/논쟁 상태와 진짜 중립을 구분 불가. |
| 출처 가중치 0 | Bloomberg와 Reddit이 동일 weight. 신뢰도 차이 무시. |
| 시간 가중치 0 | 7일 전 뉴스와 1시간 전 뉴스 동일 weight. 시장 반응의 시간 감쇠 무시. |
| 반응 강도 미반영 | 갑자기 뉴스 30개 쏟아진 종목과 3개인 종목, 평균만 봄. **attention/volume signal**(관심도 자체가 가격 동인) 누락. |
| 임계 0.15의 근거 | 슬랙 메시지의 "감정 점수 ≥ 0.15 (긍정)" 임계가 데이터 분포 분석으로 정해졌는지 단순 직관인지 불명. |

### Composite 가중치 (0.3 / 0.4 / 0.3)

| 관점 | 비판 |
|---|---|
| 가중치 근거 부재 | 산식 출처를 코드/문서에서 추적 불가. 백테스트 최적화? 직관? 다른 시스템 차용? |
| 시장 국면 불변 | Andrew Lo (Adaptive Markets): 시장 국면에 따라 같은 신호의 정보 가치가 다름. 강세 끝물엔 Tech ↓ / Sentiment ↑, 약세엔 정반대. **정적 가중치는 모든 국면에 같은 균형 강요**. |
| 신호 간 상관 미반영 | AI 모델이 Tech 지표를 학습 데이터로 썼다면 ai_score와 tech_score는 강한 상관. 단순 가중합은 같은 정보 두 번 반영. |
| 사용자 해석성 | "5.18점"이 사용자에게 약속하는 것이 불명. 며칠 안에 몇 % 오른다는 뜻? 점수와 *예측 대상*이 연결되지 않음. |

## 종합 평가

5개 산식 요소(Tech / AI / Sentiment / Composite 가중치 / Grade 임계) 중 **검증 기록이 추적 가능한 요소: 0개**.

이는 산식이 *틀렸다*는 단정이 아니다. **(a) 정량 검증된 적이 없거나, (b) 검증되었으나 그 기록이 코드/문서에 남지 않은** 상태. 어느 쪽이든 운영자/사용자/개발자 누구도 "왜 이 산식인가"에 답할 수 없다.

## 후속 작업 (별도 trace)

`docs/adr/0002`에 따라 본 trace는 (b) plan 외 별도 (c) plan으로 분리. 검증 항목 후보:

1. **신호별 경제적 의미 검토** — 각 신호가 왜 alpha를 만든다고 가정하는가의 학술적 근거 정리.
2. **신호 통계적 유효성** — 과거 데이터로 각 신호와 미래 N일 수익률의 상관계수, 정보 비율(IR) 측정.
3. **신호 간 상관관계 매트릭스** — Tech/AI/Sentiment 점수 간 상관. 0.7 이상이면 한 축 무효화 또는 직교화.
4. **가중치 최적화** — 정적 가중치를 backtest with PBO(Probability of Backtest Overfitting) 검증. regime별 동적 가중치 가능성 평가.
5. **위험 조정 수익률** — Sharpe / Sortino / max drawdown / Calmar 측정. 단순 누적 수익률만으로 평가 금지.
6. **임계값 재산정** — Grade 임계(S/A/B/C/D), RSI 임계(70), sentiment 임계(0.15) 모두 데이터 분포 + 후속 수익률 분석으로 재설정.
7. **AI 모델 자체 평가** — `predict_optimized.py` 모델의 backtest accuracy / MAE / RMSE / 방향성 정확도. 단순 회귀 vs LSTM/Transformer 비교.
