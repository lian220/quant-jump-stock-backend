# 기술적 분석

**최종 업데이트**: 2026-02-28

---

## 개요

활성 종목에 대해 SMA, RSI, MACD 등 기술적 지표를 계산하고 매수 추천 신호를 생성하는 기능.
이브닝 파이프라인(23:40 KST)에서 경제데이터 수집 완료 후 감정 분석과 함께 병렬로 자동 트리거된다.

---

## 스케줄러

| 항목 | 값 |
|------|-----|
| **트리거** | 파이프라인 체이닝 (경제데이터 수집 완료 시 자동) |
| **Pub/Sub 토픽** | `analysis-technical-request` |
| **source** | `"pipeline"` (체이닝) 또는 `"standalone"` (Admin API) |

**파이프라인 체이닝 동작 (source="pipeline"):**
- 이브닝 파이프라인(23:40)에서 경제데이터 수집 완료 → 자동 트리거
- 감정 분석과 병렬로 실행됨
- 기술적 분석 완료 시 → Vertex AI 예측 자동 트리거

**standalone 동작 (Admin API):**
- `POST /api/v1/admin/analyses/technical` → 기술적 분석만 단독 실행
- 후속 트리거 없음

### 분석 로직

**데이터 준비:**
1. PostgreSQL `stocks` 테이블에서 활성 종목 조회 (is_active=true)
2. MongoDB `daily_stock_data`에서 최근 180일 데이터 로드

**지표 계산:**

| 지표 | 파라미터 | 설명 |
|------|----------|------|
| SMA(20) | 단기 20일 | 단순이동평균 |
| SMA(50) | 장기 50일 | 단순이동평균 |
| RSI(14) | 기간 14일 | 상대강도지수 (0~100) |
| MACD | fast=12, slow=26, signal=9 | 이동평균수렴확산지수 |

**매수 신호 생성:**
```
is_recommended = golden_cross AND (rsi < 50) AND macd_buy_signal

where:
  golden_cross   = SMA(20) > SMA(50)
  macd_buy_signal = MACD > Signal Line
```

**추천 점수 계산 (recommendation_score):**
```
recommendation_score = (sma_score × 0.4) + (rsi_score × 0.3) + (macd_score × 0.3)

where:
  sma_score  = 1.0 if golden_cross else 0.0
  rsi_score  = max(0, (50 - RSI) / 50)    # RSI 낮을수록 높은 점수
  macd_score = 1.0 if macd_buy else 0.0

결과: 0.0 ~ 1.0 범위의 연속 점수
```
> `is_recommended`는 불리언(추천 여부), `recommendation_score`는 0~1 연속값(추천 강도).
