# 뉴스 감정 분석

**최종 업데이트**: 2026-02-13

---

## 개요

Alpha Vantage NEWS_SENTIMENT API를 사용하여 종목별 뉴스 감정(sentiment) 점수를 계산하는 기능.
매일 23:05(KST)에 `ParallelAnalysisJob`이 기술적 분석과 함께 병렬로 실행한다.

---

## 스케줄러

| 항목 | 값 |
|------|-----|
| **Quartz Job** | `ParallelAnalysisJob` |
| **Job 이름** | `parallelAnalysisJob` |
| **Cron 표현식** | `0 5 23 * * ?` (Asia/Seoul) |
| **실행 시간** | 매일 23:05 KST |

기술적 분석과 동일한 Job에서 병렬 실행됨. 상세는 [기술적분석.md](../technical/기술적분석.md) 참조.

---

## 파이프라인

```
23:05  ParallelAnalysisJob.execute()
       │
       └─ analysisUseCase.triggerSentimentAnalysis()
           → Kafka 발행: analysis.sentiment.request
           → Data Engine: SentimentAnalysisHandler.handle()
           → SentimentAnalysisService.analyze_sentiments()
           → MongoDB: sentiment_analysis 저장
```

## 구현 상세

### Core (Kotlin)

| 파일 | 경로 |
|------|------|
| Job | `scheduler/ParallelAnalysisJob.kt` (기술적 분석과 공유) |
| UseCase | `domain/analysis/port/input/AnalysisUseCase` |

### Data Engine (Python)

| 파일 | 경로 |
|------|------|
| Kafka 핸들러 | `adapter/input/kafka/handlers.py` → `SentimentAnalysisHandler` |
| 서비스 | `application/services/sentiment_analysis.py` → `SentimentAnalysisService` |
| Kafka 토픽 | `analysis.sentiment.request` |

### 분석 로직

**`SentimentAnalysisService.analyze_sentiments()` 처리 흐름:**

1. PostgreSQL `stocks` 테이블에서 활성 종목 조회
2. 종목별로 Alpha Vantage API 호출:
   - `function=NEWS_SENTIMENT`
   - `tickers={ticker}`
   - `time_from`: 3일 전 ~ 현재
3. 응답에서 해당 ticker의 감정 점수 추출
4. 종목별 평균 감정 점수 계산 (범위: -1.0 ~ +1.0)
5. MongoDB `sentiment_analysis` 컬렉션에 저장
6. **Rate Limiting**: 종목 간 12초 sleep (Alpha Vantage 무료 티어 제한)

## 외부 API

### Alpha Vantage — NEWS_SENTIMENT

| 항목 | 값 |
|------|-----|
| **엔드포인트** | `https://www.alphavantage.co/query?function=NEWS_SENTIMENT` |
| **설정** | `ALPHA_VANTAGE_API_KEY` 환경변수 |
| **뉴스 기간** | 최근 3일 |
| **감정 점수 범위** | -1.0 (부정) ~ +1.0 (긍정) |
| **Rate Limit** | 종목 간 12초 대기 (무료 티어: 분당 5회) |
| **프리미엄** | 분당 75회 (유료 키 사용 시) |
