## 개요

### 배경

기존 백테스트 엔진은 OHLCV(Open, High, Low, Close, Volume) 데이터만 사용했습니다. 하지만 실전 퀀트 투자에서는 다양한 보조 지표가 필요합니다:

- **감성 분석 지표**: 뉴스/소셜미디어 감성 점수
- **기술적 추천 지표**: RSI, MACD 등 기반 매수/매도 추천

### 목표

MongoDB 3개 컬렉션을 통합하여 다차원 데이터 백테스트를 지원합니다:

1. ✅ **daily_stock_data**: OHLCV 기본 데이터
2. ✅ **sentiment_analysis**: 감성 분석 점수
3. ✅ **stock_recommendations**: 기술적 추천 지표

### 핵심 가치

- **전략 다양성**: SCREENING(종목 선별) + PORTFOLIO(포트폴리오 최적화) 이원화 지원
- **데이터 유연성**: Left Join 방식으로 선택적 데이터 로드
- **실전 활용**: 감성 + 기술적 지표를 활용한 하이브리드 전략 구현

### 데이터 흐름

```
1. BacktestEngine 실행
   └─> MongoDataLoader.load() 호출

2. MongoDataLoader
   ├─> daily_stock_data 조회 (OHLCV 기본 데이터)
   ├─> sentiment_analysis 조회 (include_sentiment=True)

       ├─ sentiment_score, sentiment_count  (옵션)
       └─ is_recommended, rec_rsi, rec_score (옵션)
```

## MongoDB 컬렉션 구조

### 1. daily_stock_data (기본 OHLCV)

```json
{
  "date": "2025-01-01",
  "stocks": {
    "AAPL": {
      "open": 150.0,
      "high": 155.0,
      "low": 148.0,
      "close": 153.0,
      "volume": 1000000
    },
    "NVDA": {
      "open": 500.0,
      "high": 510.0,
      "low": 495.0,
      "close": 505.0,
      "volume": 2000000
    }
  },
  "yfinance_indicators": {
    "S&P 500 ETF": 597.20,
    "NASDAQ 100 ETF": 512.34
  },
  "fred_indicators": {
    "CPIAUCSL": 315.456,
    "UNRATE": 3.7
  }
}
```

**특징**:
- 일별 문서 구조 (date가 키)
- stocks 안에 모든 종목 데이터 포함
- **레거시 포맷 지원**: close_price만 있는 경우 OHLCV 추정

### 2. sentiment_analysis (감성 분석)

```json
{
  "ticker": "AAPL",
  "date": "2025-01-01",
  "average_sentiment_score": 0.75,
  "article_count": 10,
  "sources": ["news", "twitter", "reddit"]
}
```

**특징**:
- 종목별 문서 구조 (ticker + date가 복합 키)
- 감성 점수: -1.0 (부정) ~ 1.0 (긍정)
- 기사 수: 신뢰도 지표로 활용

### 3. stock_recommendations (기술적 추천)

```json
{
  "ticker": "AAPL",
  "date": "2025-01-01",
  "is_recommended": true,
  "rsi": 45.5,
  "recommendation_score": 0.8,
  "indicators": {
    "macd": 1.23,
    "signal": 0.98
  }
}
```

**특징**:
- 종목별 문서 구조 (ticker + date가 복합 키)
- is_recommended: 매수 추천 여부 (boolean)
- rsi: 과매수/과매도 판단
- recommendation_score: 종합 추천 점수 (0~1)

## 데이터 통합 전략

### Left Join 방식

**기본 원칙**:
- **기준**: daily_stock_data (OHLCV)
- **선택적 조인**: sentiment_analysis, stock_recommendations
- **결측값 처리**: 데이터가 없으면 기본값 사용 (0.0, False 등)

### 구현 로직

```python
# 1. OHLCV 기본 데이터 로드
loader = MongoDataLoader()
data = loader.load(
    symbols=["AAPL", "NVDA"],
    start_date=date(2025, 1, 1),
    end_date=date(2025, 1, 31),
    include_sentiment=True,           # 감성 분석 포함
    include_recommendations=True      # 기술적 추천 포함
)

# 2. 결과 DataFrame 구조
"""
date                open    high    low     close   volume  sentiment_score  sentiment_count  is_recommended  rec_rsi  rec_score
2025-01-01 00:00:00 150.0   155.0   148.0   153.0   1000000  0.75            10               True            45.5     0.8
2025-01-02 00:00:00 153.0   158.0   152.0   157.0   1200000  0.80            12               True            48.2     0.85
2025-01-03 00:00:00 157.0   160.0   155.0   158.0   900000   0.0             0                False           0.0      0.0
"""
```

### Left Join 알고리즘

```python
# MongoDataLoader.load() 내부 로직

# Step 1: OHLCV 데이터 로드
documents = coll.find({"date": {"$gte": start_date, "$lte": end_date}})

# Step 2: 감성 분석 데이터 로드 (옵션)
if include_sentiment:
    sentiment_data = {
        (doc["ticker"], doc["date"]): doc
        for doc in sentiment_coll.find(...)
    }

# Step 3: 추천 데이터 로드 (옵션)
if include_recommendations:
    recommendation_data = {
        (doc["ticker"], doc["date"]): doc
        for doc in rec_coll.find(...)
    }

# Step 4: Left Join 수행
for symbol in symbols:
    for doc in documents:
        date_str = doc["date"]

        # OHLCV 기본 레코드 생성
        record = {
            "date": pd.Timestamp(date_str),
            "open": ...,
            "close": ...,
            # ...
        }

        # Left Join: 감성 분석
        if include_sentiment:
            sent_key = (symbol, date_str)
            sent_doc = sentiment_data.get(sent_key)
            if sent_doc:
                record["sentiment_score"] = sent_doc["average_sentiment_score"]
                record["sentiment_count"] = sent_doc["article_count"]
            else:
                record["sentiment_score"] = 0.0
                record["sentiment_count"] = 0

        # Left Join: 추천 데이터
        if include_recommendations:
            rec_key = (symbol, date_str)
            rec_doc = recommendation_data.get(rec_key)
            if rec_doc:
                record["is_recommended"] = rec_doc["is_recommended"]
                record["rec_rsi"] = rec_doc["rsi"]
                record["rec_score"] = rec_doc["recommendation_score"]
            else:
                record["is_recommended"] = False
                record["rec_rsi"] = 0.0
                record["rec_score"] = 0.0

        records.append(record)
```

### 레거시 데이터 처리

**문제**: 초기 데이터는 `close_price`만 존재 (OHLCV 중 O/H/L/V 없음)

**해결책**: 추정 배율 사용

```python
# 레거시 포맷 감지
if "open" not in stock_data:
    # close_price로 OHLCV 추정
    close = stock_data["close_price"]
    record.update({
        "open": close * 0.998,   # -0.2%
        "high": close * 1.005,   # +0.5%
        "low": close * 0.995,    # -0.5%
        "close": close,
        "volume": 1_000_000      # 기본값
    })
```

## 사용 예시

### 1. 감성 기반 SCREENING 전략

```python
# scripts/backtest_sentiment_strategy.py

from application.backtest.data_loader_mongo import MongoDataLoader

# 데이터 로드 (감성 분석 포함)
loader = MongoDataLoader()
data = loader.load(
    symbols=["AAPL", "NVDA", "TSLA"],
    start_date=date(2025, 1, 1),
    end_date=date(2025, 1, 31),
    include_sentiment=True
)

# SCREENING 조건: 감성 점수 > 0.2 AND 기사 수 >= 10
for symbol, df in data.items():
    candidates = df[
        (df["sentiment_score"] > 0.2) &
        (df["sentiment_count"] >= 10)
    ]
    print(f"{symbol}: {len(candidates)} days qualified")
```

**출력 예시**:
```
AAPL: 15 days qualified
NVDA: 20 days qualified
TSLA: 8 days qualified
```

### 2. 하이브리드 전략 (감성 + 기술적 지표)

```python
# 감성 + 추천 모두 활용
data = loader.load(
    symbols=["AAPL", "NVDA"],
    start_date=date(2025, 1, 1),
    end_date=date(2025, 1, 31),
    include_sentiment=True,
    include_recommendations=True
)

# SCREENING 조건: 감성 긍정 + 기술적 매수 추천
for symbol, df in data.items():
    candidates = df[
        (df["sentiment_score"] > 0.3) &
        (df["is_recommended"] == True) &
        (df["rec_rsi"] < 70)  # 과매수 제외
    ]
    print(f"{symbol}: {len(candidates)} days qualified (hybrid)")
```

## 성능 및 확장성

### 성능 최적화

#### 1. 인덱스 전략

```javascript
// MongoDB 인덱스 생성
db.daily_stock_data.createIndex({ date: 1 });
db.sentiment_analysis.createIndex({ ticker: 1, date: 1 });
db.stock_recommendations.createIndex({ ticker: 1, date: 1 });
```

**효과**:
- 날짜 범위 쿼리 성능 향상 (O(log n))
- Left Join 성능 향상 (dict lookup O(1))

#### 2. 버퍼링 전략

```python
# 지표 계산을 위한 추가 버퍼 (이동평균 등)
loader = MongoDataLoader(add_buffer_days=50)

# 실제 로드: start_date - 50일 ~ end_date
data = loader.load(
    symbols=["AAPL"],
    start_date=date(2025, 1, 1),  # 내부적으로 2024-11-12부터 로드
    end_date=date(2025, 1, 31)
)
```

**효과**:
- 이동평균 등 기술적 지표 정확도 향상
- 백테스트 초반 warm-up 기간 확보

#### 3. 메모리 관리

```python

for symbol in large_symbol_list:
```
