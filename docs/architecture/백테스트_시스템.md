## 데이터 흐름

```
1. 백테스트 실행 요청
   └─> BacktestEngine.run(strategy, symbols, date_range)

2. 데이터 로딩
   └─> MongoDataLoader.load()
       ├─> daily_stock_data 조회 (OHLCV 기본)
       ├─> sentiment_analysis 조회 (감성 분석, 옵션)
       ├─> stock_recommendations 조회 (기술적 지표, 옵션)
       └─> Left Join 수행

3. 전략 적용
   └─> StrategyInterpreter.apply(data, strategy)
       ├─> 매수/매도 신호 생성
       └─> 리스크 관리 (Stop Loss, Take Profit)

4. 포트폴리오 시뮬레이션
   └─> Portfolio.execute_trades()
       ├─> 주문 체결 시뮬레이션
       ├─> 포지션 관리
       └─> Equity Curve 생성

5. 성과 지표 계산
   └─> PerformanceMetrics.calculate()
       ├─> CAGR, MDD, Sharpe Ratio
       ├─> 승률, Profit Factor
       └─> 월별/일별 수익률
```

## 핵심 컴포넌트

### 1. 데이터 계층
- **MongoDataLoader**: MongoDB 3개 컬렉션 통합
- **YFinanceDataLoader**: Yahoo Finance API 연동
- **PandasDataLoader**: 테스트용 데이터 로더

### 2. 전략 계층
- **StrategyDefinition**: 전략 DSL 정의
- **StrategyInterpreter**: 전략 로직 실행
- **IndicatorCalculator**: 기술적 지표 계산

### 3. 실행 계층
- **BacktestEngine**: 백테스트 실행 엔진
- **Portfolio**: 포트폴리오 시뮬레이션
- **RiskManager**: 리스크 관리 (손절/익절)

### 4. 분석 계층
- **PerformanceMetrics**: 성과 지표 계산
- **TradeAnalyzer**: 거래 분석
- **EquityCurve**: 자산 곡선 생성

## 데이터 통합 전략

### Left Join 방식
- **기준**: daily_stock_data (OHLCV)
- **선택적 조인**: sentiment_analysis, stock_recommendations
- **결측값 처리**: 데이터 없으면 기본값 (0.0, False)

### 결과 DataFrame 구조
```
date        | open  | high  | low   | close | volume  | sentiment_score | is_recommended | rec_rsi
2025-01-01  | 150.0 | 155.0 | 148.0 | 153.0 | 1000000 | 0.75           | True           | 45.5
2025-01-02  | 153.0 | 158.0 | 152.0 | 157.0 | 1200000 | 0.80           | True           | 48.2
```

## 주요 특징

### 1. 다차원 데이터 지원
- OHLCV (가격/거래량)
- 감성 분석 (뉴스/소셜미디어)
- 기술적 지표 (RSI, MACD 등)

### 2. 전략 유연성
- **SCREENING**: 조건으로 종목 선별
- **PORTFOLIO**: 고정 포트폴리오

### 3. 정밀한 시뮬레이션
- Decimal 타입 (금융 정밀도)
- 수수료/슬리피지 반영
- Stop Loss/Take Profit 지원
