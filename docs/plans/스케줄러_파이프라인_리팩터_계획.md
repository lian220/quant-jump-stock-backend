## 배경 (구조적 문제)

### 이전 타임라인 (Phase 1 이전)

```
06:05  EconomicDataUpdateJob      → FRED + Yahoo Finance 수집
22:00  EconomicDataUpdate2Job     → 경제 데이터 재수집 + Vertex AI 예측 (동일 Job)
23:05  ParallelAnalysisJob        → 기술적 분석 + 감정 분석
00:30  AutoBuyJob                 → 자동 매수
```

### 3가지 문제점

1. **EST 시간대 이슈**: 22:00 실행 시 CPI/NFP(22:30 KST, EST 기간) 미발표 상태로 수집
2. **Vertex AI 레이스 컨디션**: `.get()`이 Pub/Sub 발행만 대기 → 데이터 수집 완료 전 Vertex AI 실행
3. **기술적 분석 누락**: 22:00에 Vertex AI 실행 → 23:05 기술적 분석 결과 없이 예측

### 해결 과정

| Phase | 해결 방식 | 상태 |
|-------|----------|------|
| Phase 1 | 시간 조정 (23:00 → 23:30 → 23:45) | ✅ 완료 |
| Phase 2 | Vertex AI 별도 Job 분리 + 종목추천 Job 추가 | ✅ 완료 |
| Phase 2-3 (C) | 45분 시간 버퍼로 암묵적 보장 | ✅ 임시 적용 |
| **Phase 2-3 (D)** | **Pub/Sub 파이프라인 체이닝 (완료 이벤트 기반)** | ✅ **최종 구현** |

## 최종 아키텍처 (현재)

```
── Cloud Scheduler (데이터 파이프라인) ──────────────────────────
06:05  morning-economic-data     → 경제데이터 수집 (standalone)
22~06  news-collection           → 뉴스 수집 (1분 간격)
06~22  news-collection-offhours  → 뉴스 수집 (5분 간격)
23:40  evening-pipeline          → 경제데이터 → 분석 → Vertex AI (pipeline, 체이닝)
00:20  stock-recommendation      → 종목 추천 (standalone)

── Core Quartz (트레이딩) ──────────────────────────────────────
00:30  AutoBuyJobAdapter         → 자동 매수
매1분  AutoSellJobAdapter        → 자동 매도 체크
06:30  CleanupOrdersJobAdapter   → 미체결 주문 정리
07:00  PortfolioProfitReportJob  → 포트폴리오 수익 보고

── Core Quartz (백테스트) ──────────────────────────────────────
일 02:00  CanonicalBacktestJob   → PUBLISHED 전략 대표 백테스트
매일 03:00  BacktestCleanupJob   → RUNNING 타임아웃, 초과 아카이브 정리
```

### 파이프라인 체이닝 흐름

```
Cloud Scheduler (23:40) → Pub/Sub economic-data-update-request (source="pipeline")
  → Data Engine: 경제데이터 수집 완료
  → Data Engine: 기술적 분석 + 감정 분석 (병렬, 자동 트리거)
  → Data Engine: Vertex AI 예측 (기술적 분석 완료 시 자동 트리거)

Cloud Scheduler (00:20) → Pub/Sub analysis-recommendation-request (source="standalone")
  → Data Engine: 종목 추천 실행 (단독)
```

## 남은 선택적 항목

### Phase 3: ISM PMI 대응 (선택, 미구현)

- ISM PMI: 10:00 AM ET = 00:00 KST(EST) / 23:00 KST(EDT)
- 현재 23:40 파이프라인으로는 EST 기간 ISM PMI 미포함
- 월 1회 지표 → 1일 지연 허용 (06:05 수집에서 포함)

### Phase 3: 서머타임 자동 전환 (선택, 미구현)

- 현재: 고정 크론 스케줄 (KST 기준) + 충분한 시간 버퍼
- 23:40 실행: EST 기간에도 CPI/NFP(22:30) 발표 후 70분 여유

## 참고: 수집 데이터 정리

### `collect_economic_data()` 에서 수집하는 전체 데이터

| 구분 | 소스 | 항목수 | 내용 |
|------|------|--------|------|
| FRED 지표 | FRED API | 16개 | 기준금리, 실업률, CPI, GDP, 국채금리 등 |
| Yahoo Finance 지표 | yfinance | 24개 | S&P500, VIX, 금, 달러인덱스 등 |
| 개별 종목 | yfinance | 35개 | OHLCV + 펀더멘탈 ~40개 필드 |

> 주가 데이터는 경제 데이터 수집에서 함께 채워짐
> 기술적 분석(SMA/RSI/MACD)은 파이프라인 체이닝으로 자동 실행
